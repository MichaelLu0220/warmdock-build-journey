# Contributing

Small improvements are welcome: clearer writing, accessible examples, tests,
and fixes to the public playground.

Please do not submit:

- reverse-engineered production code;
- real task titles or other personal data;
- credentials or deployment details;
- a “complete clone” of the private application.

Run the checks before opening a pull request:

```bash
npm test
```

The best contribution to this repository is one that makes an idea easier to
understand without making the private system easier to reconstruct.
